\chapter{Phenomenological Reference Atlas}
\label{app:paper_eqs_reference_atlas}

This appendix collects supplementary reference figures and exploratory material that support the spectroscopy analysis developed in the main chapter. For the monomer, it gathers the validation atlas, the disorder-convergence sweeps, and the higher-field sensitivity runs. For the dimer, it assembles the control panels, the waiting-time series, and the apodization study used alongside the main discussion.

For the monomer, the atlas is built directly from the copied \texttt{essential\_results} run set. The standardized validation and waiting-time runs use pulse amplitudes $(0.002,0.002,0.002)$ across the selected Lindblad and homogeneous Redfield jobs. A supplementary Fig.~4 sensitivity set with stronger pulses $(0.005,0.005,0.005)$ is collected later in this appendix.
