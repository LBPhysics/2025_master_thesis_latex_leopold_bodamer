\chapter{Phenomenological Reference Atlas}
\label{app:paper_eqs_reference_atlas}

This appendix collects the paper-equation reference figures and supplementary exploratory material that support the solver calibration developed in the main chapter. It provides the complete comparison atlas for the monomer and dimer and documents additional sensitivity studies that help interpret the selected figure set.

For the monomer, the validation atlas is built directly from the copied \texttt{essential\_results} run set. The standardized calibration and waiting-time runs use pulse amplitudes $(0.002,0.002,0.002)$ across the selected \texttt{paper\_eqs}, Lindblad, and homogeneous Redfield jobs. A supplementary Fig.~4 sensitivity set with stronger pulses $(0.005,0.005,0.005)$ is collected later in this appendix.
